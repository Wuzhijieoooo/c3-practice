# C3 通勤刷题

专门用于这份安全员 C3 题库的个人刷题网页应用。Safari 添加到 iPhone 主屏幕后可像 App 一样打开；完成首次缓存后可离线刷题。免登录，无后端、无运行时第三方依赖。

## 功能与使用

- 顺序刷题，每组最多 10 题；另有随机练习和错题重刷。
- 答题页点击模式旁的「⇄ 切换」，或在首页打开「专项练习」，可随时切换顺序、随机、错题、单选、多选、判断和收藏练习。
- 每种模式分别保留一组未完成练习，包括题目顺序、当前题、已答答案及多选草稿；切回原模式会继续这一组，完成后才抽取下一组。刷新或离线重开也能恢复。
- 首页「模拟考试」或「专项练习 → 模拟考试」提供整卷自测：100 题（单选 40、多选 20、判断 40），60 分钟，每题 1 分，60 分达标。以上为应用自测规则，开考前会显示。
- 考试中不显示对错，可修改/取消答案、用答题卡跳题；提前交卷需确认，截止时间到后自动交卷。多选必须全对才得分，错题和未答题收进错题本。
- 模拟考试单独保存一份未完成试卷和最近一次成绩，与各模式练习进度分别保存。交卷后可查看成绩、错题及未答题对应的题库答案，或进入错题练习。
- 单选、多选、判断专项每组随机抽取最多 10 题，不改变顺序刷题进度。
- 答题页与错题回顾可收藏/取消收藏；在「收藏练习」或「专项练习 → 收藏练习」重刷。收藏题答对后仍保留，只有手动取消才移出。
- 完成一组后可「查看本组错题」，对照当时的选择与题库答案，并「重练本组错题」。只保留最近完成的一组，也可从「专项练习」进入上一组回顾。
- 单选、判断点选后判分；多选选完后提交，必须与原答案完全一致。
- 即时显示题库原答案及对应选项全文，多选题额外标出错选、漏选；错题自动收集，重新答对后移出。
- 本组练习支持「上一题」只读回看，返回当前题后保留未提交的多选草稿；回看不重复计分、不改变已保存的答题进度。完成本组后仍通过本组回顾查看错题。
- 首页「设置」可选择标准/大字，应用于练习、考试和错题回顾；字号在当前设备保存。安装与离线使用说明也在设置中。
- 保存答题记录、当前组、当前题和未提交多选草稿，关闭后可以继续。
- 全部 2000 题：800 单选、400 多选、800 判断。
- 首页突出开始/继续答题，以及专项练习、错题复习、模拟考试，收藏与设置独立入口；随机练习位于专项练习列表。常见手机视口一屏显示，特别矮的窗口允许内容区滚动，保证入口可达。
- 加载页和所有页面共用固定外壳，禁止整页上下拖动，隐藏滚动条；长题、练习列表、错题回顾及过长的答案反馈仍可在内容区滚动。旧版 Safari 使用触摸边界处理阻止整页回弹，双指缩放保留。
- 普通答题页精简顶部，只显示返回、模式、题号和切换；PDF 来源可展开查看。反馈及上一题/提交/下一题固定底部，多选保持滚动位置。
- 选项点按回弹、答题反馈、切题与进度动画；完成一组时徽章弹出，全对时短暂彩纸庆祝。动画不阻塞操作，开启系统“减少动态效果”后关闭。

切换列表显示各模式当前题号，绿色标记正在练习的模式；从答题页进入后，点返回箭头可直接回到当前题。切到空的错题本或收藏夹时不会改变当前练习。已开始的错题/收藏组保持原题目，答对或取消收藏不会改动未完成组。

完成一组后，首页优先提供未完成的顺序练习，也可在切换列表继续其他模式。本组错题重练也可暂停与继续；有未完成重练时，入口显示「继续上次错题重练」，保留原来的错题组。完成任何模式后，它会成为最近完成的一组用于回顾。

考试采用实际截止时间，切换练习、刷新或关闭页面不会暂停或重置倒计时；关闭期间到期的试卷，会在重新打开应用时结算。考试选项每次变更即保存，交卷时统一更新答题记录，不改变普通练习的题号或草稿。本组练习回顾与考试结果分别保留。

没有题目解析、账号或云同步。进度保存在当前设备当前网站的本地存储中，切换域名、清除网站数据或重新安装可能导致进度不可用。Safari 和主屏幕应用的存储可能独立，建议安装后始终从主屏幕进入。

## 电脑预览

在项目目录执行（只需 Python 3；有 Node.js 时也可使用 `npm start`）：

```sh
python3 -m http.server 4173 --directory public
```

访问 http://localhost:4173 。不要直接双击 `index.html`，因为模块和题库需要通过 HTTP 加载。

电脑上的 `localhost` 支持离线缓存。手机访问电脑的局域网 HTTP 地址只能预览，不能可靠安装离线应用；正式手机使用需要 HTTPS。

## iPhone 安装：静态托管即可

### GitHub Pages（免自有域名）

项目已提供 `.github/workflows/pages.yml`，推送 `master` 后自动发布 `public`，无需构建命令或额外依赖。

1. 打开 GitHub 仓库 `Wuzhijieoooo/c3-practice`，选择 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。不要选择 Deploy from a branch，因为实际网站在 `public` 内。
3. 在项目目录执行 `git add .`、`git commit -m "配置 GitHub Pages 自动部署"`、`git push origin master`。
4. 打开 **Actions → Deploy GitHub Pages**，等待工作流成功。若配置 Pages 前已推送，选择 **Run workflow → master → Run workflow** 重试。
5. 以 **Settings → Pages** 或部署任务显示的正式地址为准；此仓库预期地址为 `https://wuzhijieoooo.github.io/c3-practice/`，包含项目名和末尾斜杠。
6. iPhone Safari 打开正式地址，添加到主屏幕并等待“离线可用”，再断网验证。

GitHub Free 的 Pages 需要公开仓库；如果 Pages 提示升级套餐，先检查仓库是否为私有。无需自定义域名、临时 token 或新增密钥。正式网站内容公开访问。

应用路径使用相对地址，支持 `/c3-practice/` 子路径。换到 GitHub Pages 后，旧域名的答题进度不会自动迁移。若以后将分支改成 `main`，同步修改工作流的 `branches`。

### 上传到其他静态托管平台

1. 执行 `python3 scripts/package_site.py`，生成 `dist/c3-practice-site.zip`。
2. 解压到一个新目录，把其中完整网站目录上传到支持 HTTPS 的静态托管平台。例如登录 [Netlify Drop](https://app.netlify.com/drop)，拖入解压后的目录；也可使用 Cloudflare Pages 的直接上传方式。不需要构建命令。
3. 用 iPhone Safari 打开托管平台给出的 HTTPS 地址。
4. 点击「分享」→「添加到主屏幕」，从主屏幕打开并保持联网，直到显示「离线可用」。
5. 关闭网络，再重新打开检查能否刷题。以后通勤时可离线使用。

**本项目未公开发布。** 静态部署会让持有链接的人下载题库，请在发布前确认这符合你的题库使用范围。应用不会上传答题记录，但托管平台可能记录普通访问日志。若需要保密，可在托管平台加访问控制。

`public` 是唯一需要部署的目录；不要部署源码目录、原始 PDF 或整个工作区。压缩包内的 `index.html` 位于根目录，支持部署在子路径。

## 题库来源与导入

来源：`安全员C3题库25年7月最新.pdf`，106 页，2025 年 7 月版本。题库包含上海地方条文，应用仅保留原文与原答案，不将其视为现行法规核验结果。

答案从原 PDF 紫色背景选项单元格提取，而不是推测。原 PDF 中 171 题有文字溢出单元格，提取脚本按原始字符绘制顺序还原所属题目，避免邻题内容混入。

6 道多选题仅高亮一个答案：1036、1038、1042、1103、1125、1160。保留原答案，答题后显示提示；详细审计和来源 SHA256 在 `public/import-report.json`。

重新导入（需要 Python 包 `pdfplumber`）：

```sh
python3 scripts/extract_questions.py /完整路径/安全员C3题库25年7月最新.pdf
```

原 PDF 不在项目内，也不会包含在部署包中。
